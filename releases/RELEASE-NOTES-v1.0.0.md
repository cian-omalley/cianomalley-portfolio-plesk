**Digital District** — a dynamic, animated cyberpunk-brutalist WordPress theme with no page builder, ready to run on Plesk (or any WordPress host).

### Download & use
- **`cianomalley-portfolio-complete.zip`** — everything in one: the theme, an offline clickable preview (`preview-demo.html`), and setup guides. Start with `START-HERE.md`.
- **`digital-district.zip`** — just the theme, to upload via wp-admin → Appearance → Themes → Add New → Upload Theme → Activate.

### What's inside
- Custom post types with their own case-study pages: Client Work, Projects, Guides, Reviews — plus a Blog.
- **Live GitHub sync** — imports every repo from your account into Projects (one-click re-sync in wp-admin).
- Honest statuses everywhere (In Progress / Planning / Complete / …) and star-rated reviews.
- Artistic & interactive: animated neon-skyline hero with aurora + scanline, cursor-follow 3D card tilt + spotlight, text-decode HUD, reading-progress bar, count-up stats, an Esc command menu.
- Self-hosted fonts, no external calls, `title-tag` support so any SEO plugin controls meta.
- Accessible baseline (landmarks, skip link, focus rings, reduced-motion) and fully responsive.

On activation the theme builds all pages, the nav menu, sample content, imports your repos, and flushes permalinks — see `INSTALL-ON-PLESK.md`.
